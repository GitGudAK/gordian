**Public API (CONTEXT.md locked decisions + orchestrator scope constraints):**

```
POST /v1/session-plan
  Headers: X-Device-ID: <UUID>          (opaque device id — launch attestation lane)
  Body:    { "scenario": string }        (≤ MAX_SCENARIO_CHARS)
  200:     { "mode": "YES_NO"|"BINARY", "optionA": string, "optionB": string, "questions": string[] }
           + response header X-Weekly-Sessions: <int>   (freemium meter read, Phase 3.5)

POST /v1/verdict
  Headers: X-Device-ID: <UUID>
  Body:    { "scenario": string, "answers": [{ "question": string, "choice": string, "reflection": string }] }
  200:     { "decision": string, "sentiment": string, "analysis": string, "probe": string }

GET /v1/guides            → 404 { "error": { "code": "not_found", "message": "guides not yet available" } }  (reserved route)
any other route/method    → 404 { "error": { "code": "not_found" } }

Error envelope (every failure): { "error": { "code": string, "message": string } }
Codes → HTTP status:
  bad_request → 400 · rate_limited → 429 · weekly_meter_exhausted → 429 (RESERVED: defined in the
  plan 01-01 error-code union, never returned this phase) · spend_cap → 429 · upstream_error → 502 · not_found → 404
```

From plan 01-01 (use directly, no exploration): the Provider interface and error-code union in proxy/src/providers/types.ts; operation prompt builders, user messages, temperature, and both schema dialects exported from proxy/src/operations.ts; the Gemini/Anthropic adapters in proxy/src/providers/. Worker vars (already in wrangler.jsonc): MODEL_SESSION_PLAN, MODEL_VERDICT ("{provider}:{model}"), DAILY_CALL_CAP, RATE_LIMIT_CALLS, RATE_LIMIT_WINDOW_MIN, DEVICE_DAILY_SESSIONS, MAX_SCENARIO_CHARS.
